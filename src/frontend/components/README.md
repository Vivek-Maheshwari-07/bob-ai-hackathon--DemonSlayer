# Frontend Components

Modular UI components organized by domain area:
- `common/`: Shared layout, headers, navigation bars, and buttons.
- `safety/`: Signal alert badges, PRR metric cards, and event trend charts.
- `ctd/`: Module 1–5 readiness cards, gap tables, and dossier folder tree views.
- `copilot/`: IBM Bob chat panel, streaming message cards, and suggestion chips.
